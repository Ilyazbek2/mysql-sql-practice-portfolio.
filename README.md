
# MySQL SQL Practice Portfolio

A collection of five SQL challenges demonstrating practical MySQL skills for data analytics.

## Skills Demonstrated

- JOIN operations
- Aggregate functions: COUNT, SUM, AVG, MAX
- GROUP BY and HAVING
- WHERE and ORDER BY
- Subqueries
- String functions
- Date and time functions
- Data analysis using SQL

## Requirements

- MySQL 8.0+
- MySQL Workbench or another MySQL client

## How to Run

1. Run `sql/00_setup.sql`.
2. Open a problem file from the `problems/` folder.
3. Try to solve the challenge independently.
4. Compare your result with the matching file in `solutions/`.

## Challenges

1. Monthly average product ratings.
2. Rooms rented an odd number of times.
3. Completed booking revenue by city.
4. Passengers with the longest full name.
5. Time between the beginning of lesson 2 and the end of lesson 4.

All sample records are fictional and provided for educational purposes.
